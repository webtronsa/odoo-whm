# Contributors to WHM Hosting Management

This module was developed as a comprehensive WHM/cPanel hosting management solution for Odoo 19.

## Development Team

- **Lead Developer**: WHM Hosting Solutions Team
- **Architecture**: Based on WHMCS functionality patterns
- **Odoo Integration**: Full integration with Odoo 19 ecosystem

## Credits

This module was originally adapted from the H3C CloudOS integration codebase and completely restructured to focus on WHM/cPanel hosting management functionality.

## Contributing

We welcome contributions to improve this module. Please follow these guidelines:

1. **Code Style**: Follow Odoo coding standards
2. **Testing**: Include tests for new features
3. **Documentation**: Update documentation for changes
4. **Security**: Ensure all user inputs are properly validated
